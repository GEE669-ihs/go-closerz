# GO Closerz — React + Vite

    npm install
    npm run dev      # development
    npm run build    # output ke folder dist/

Login/Sign up memakai localStorage (simulasi, belum ada backend). Di desktop, form login dan pengenalan photocard tampil berdampingan; di mobile, pengenalan kartu tersedia dengan scroll setelah layar login. Beranda hanya terbuka setelah login. Setelah daftar, email akun akan terisi di halaman login.
Tanggal penutupan PO diatur di `src/data.js` (PO_END).
