# GO Closerz — React + Vite

    npm install
    npm run dev      # development
    npm run build    # output ke folder dist/

Login/Sign up memakai localStorage (simulasi, belum ada backend). Halaman login dan pengenalan photocard ditampilkan sebagai dua layar vertikal; beranda hanya terbuka setelah login. Setelah daftar, email akun akan terisi di halaman login.
Tanggal penutupan PO diatur di `src/data.js` (PO_END).
